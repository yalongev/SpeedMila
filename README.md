# SpeedMila ⚡ (בליץ-מילה)

**SpeedMila** היא אפליקציית מובייל קלילה וממכרת לאימון קריאה מהירה, צמצום מרכז הראייה (Foveal Vision Training) ושיפור הזיכרון החזותי. האפליקציה מעוצבת בממשק Dark Mode יוקרתי, דינמי ובעל ניגודיות גבוהה.

האפליקציה משלבת בין עולמות ה-Brain Training לבין חוויית משחק (Gamification) מהירה: המשתמש צריך לקלוט מילים או ביטויים שלמים שמועפים על המסך לשבריר שנייה (באמצעות מנגנון טכיסטוסקופ) - ולזהות אותם מתוך ארבע אפשרויות.

---

## 🚀 זרימת האפליקציה (User Flow)

1.  **מסך פתיחה ואונבורדינג (Onboarding Quiz):** שאלון אינטראקטיבי קצר לקביעת מטרות (פסיכומטרי, קריאת ספרים, מיקוד) ויעדי מוטיבציה יומיים.
2.  **סנכרון פרופיל והרשאות:** בחירת חשבון לסנכרון הענן (**Google Account** או **Apple ID**) לשמירת התקדמות וטעינת פרופיל משתמש מאומת (V V V V).
3.  **מסך הבית (Home):** בחירת סוג האימון (אישי, אתגר קבוצתי, מרתון משפטים).
4.  **לובי הגדרות (Lobby):** קביעת רמת הקושי, אורך הביטוי וגודל הגופן (עד גופן "פיצי" לאימון מתקדם).
5.  **זירת המשחק (Game Arena):** חלון הבזק מהיר ומנגנון "קפיץ" דינמי המגביר את המהירות בכל תשובה נכונה.
6.  **לוח בקרה וסטטיסטיקה (Dashboard):** מסך מעקב ביצועים מתקדם בהשראת אפליקציות כושר מובילות.

---

## ✨ פיצ'רים מרכזיים (Features)

*   **מנגנון טכיסטוסקופ (Tachistoscope Engine):** הבזק חזותי מדויק של מילים מבוסס מילי-שניות (מתחיל ב-300ms ויורד ב-30ms בכל תשובה נכונה).
*   **ממשק ניקוד והישגים יוקרתי (Neon Lime UI):** עיצוב בהשראת קובץ 76.jpg המציג:
    *   **פנל ראשי ענק:** מציג את הניקוד היומי או מהירות שיא נוכחית.
    *   **פנלים משניים:** חלוקה ממוקדת של הישגים לפי שבוע (Week), חודש (Month) וסך הכל (Total).
*   **גרף תצפית והתמדה (Activity Matrix):** מטריצת ריבועי פעילות (Contribution Grid) המציגה את ימי האימון וההתמדה השבועית (Mon-Sun), עם תצוגת גרף ביצועים ל-7 ימים ול-30 יום.
*   **גלגלי הצלה מובנים:** מנגנון חצי-חצי (50:50) והארכת זמן (🕒+) מובנים ב-UI של זירת המשחק.

## 🛠️ טכנולוגיות (Tech Stack)

הפרויקט בנוי בטכנולוגיות צד לקוח נקיות (Vanilla Web Tech) ומותאם לחלוטין למובייל:
*   **HTML5** – מבנה סמנטי של דפי האפליקציה ומסכי המודאל.
*   **CSS3** – עיצוב Modern Ultra-Dark Mode, שימוש ב-Flexbox ו-Grid לפריסה מושלמת, ואנימציות מעבר חלקות.
*   **JavaScript (ES6+)** – ניהול סטייט מקומי (`localStorage`), טיימרים אסינכרוניים, ולוגיקת הגרלת ביטויים ומסיחים.
