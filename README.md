# SpeedMila ⚡ (בליץ-מילה)

**SpeedMila** היא אפליקציית מובייל קלילה וממכרת לאימון קריאה מהירה וצמצום מרכז הראייה (Foveal Vision Training), המעוצבת בממשק כהה, דינמי ויוקרתי.

האפליקציה משלבת בין עולמות ה-Brain Training לבין חוויית משחק (Gamification) מהירה, בה המשתמש צריך לקלוט מילים או ביטויים שלמים שמועפים על המסך לשבריר שנייה - ולזהות אותם מתוך ארבע אפשרויות.

---

## ✨ פיצ'רים מרכזיים (Features)

*   **מנגנון טכיסטוסקופ (Tachistoscope Engine):** הבזק חזותי מדויק של מילים ללא השהיות דפדפן.
*   **מנגנון "קפיץ" דינמי:** ככל שעונים נכון, מהירות ההבזק עולה (זמן החשיפה מתקצר ב-30 מילי-שניות בכל תשובה נכונה). טעות מאפסת את הקצב חזרה למצב בטוח.
*   **התאמה אישית של שלבים (Lobby Settings):** 
    *   שליטה באורך הביטוי (ממילה בודדת ועד משפט מורכב של 4 מילים).
    *   שליטה בגודל הגופן - מאותיות גדולות ועד גופן "פיצי" לאימון ראייה ממוקד.
*   **ממשק מעוצב ואינטראקטיבי:** טיימר עגול של 15 שניות לכל שאלה, כפתורי גלולה (Capsules) חלקים בפריסת 2 בשורה, ואפקטים של דעיכת כפתורים (Fade) בתשובה נכונה/שגויה.

## 🛠️ טכנולוגיות (Tech Stack)

הפרויקט בנוי בטכנולוגיות צד לקוח נקיות (Vanilla Web Tech) ומותאם לחלוטין למובייל:
*   **HTML5** – מבנה סמנטי של שלושה דפים (דף בית, לובי הגדרות, וזירת משחק).
*   **CSS3** – עיצוב Modern Dark Mode, שימוש ב-Flexbox ו-Grid לפריסה מושלמת, ואנימציות מעבר חלקות.
*   **JavaScript (ES6+)** – ניהול סטייט מקומי (`localStorage`), טיימרים אסינכרוניים, ולוגיקת הגרלת ביטויים ומסיחים.

## ▶️ איך מריצים את הפרויקט

הפרויקט הוא אפליקציית Frontend סטטית, לכן **לא חובה Node.js**.

אפשרות מומלצת (בלי התקנות מיוחדות, באמצעות Python):

```bash
cd /path/to/SpeedMila
python3 -m http.server 5500
```

ואז לפתוח בדפדפן:

```text
http://localhost:5500
```

אפשרות עם Node.js (אם כבר מותקן אצלך):

```bash
npx serve . -l 5500
```

ולפתוח:

```text
http://localhost:5500
```

הערה: עדיף להריץ דרך שרת מקומי (ולא בלחיצה ישירה על קובץ HTML), כדי למנוע בעיות תאימות בין דפדפנים.
